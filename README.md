# Jiung Moon — portfolio

A static site: open `dist/index.html` through any static server
(e.g. `python3 -m http.server 4173 --directory dist`). Every push to `main`
runs the tests in `tests/` and publishes `dist/` to GitHub Pages
(`.github/workflows/pages.yml`). Working notes live in `docs/HANDOFF.md`.
